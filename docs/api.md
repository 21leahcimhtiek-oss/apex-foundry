# API reference

Base URL (local dev): `http://localhost:8000`. Interactive docs:
`http://localhost:8000/docs` (Swagger UI, generated by FastAPI).

## Health

### `GET /health`
Liveness + version.
```json
{"status": "ok", "version": "0.1.0"}
```

### `GET /ready`
Readiness probe.
```json
{"status": "ready"}
```

## Agents

### `GET /agents`
All registered blueprints.
```json
[
  {"name": "Ops Commander", "tier": 1, "tools": ["http_fetch"], "tags": ["ops", "commander"]}
]
```

### `GET /agents/{name}`
One blueprint. `404` if the name isn't registered.
```json
{"name": "Research Specialist", "tier": 2, "tools": ["http_fetch"], "persona": "You are a research specialist..."}
```

## Chat

### `POST /chat`
Main inference entrypoint.

Request (`ChatRequest`):
| Field    | Type          | Constraints        | Notes                                    |
|----------|---------------|--------------------|------------------------------------------|
| `message`| string        | 1–32 000 chars     | required                                 |
| `agent`  | string \| null| —                  | blueprint `name`; 404 if unknown         |
| `intent` | string \| null| —                  | overrides heuristic intent extraction    |

```bash
curl -X POST localhost:8000/chat \
  -H 'content-type: application/json' \
  -d '{"message": "Compare Redis and Memcached", "agent": "Research Specialist"}'
```

Response (`ChatResponse`):
```json
{"reply": "...", "intent": "research", "model": "openrouter/auto"}
```

Behavior:
- With `agent`: routed to a Commander (tier 1) or Specialist per the
  blueprint; specialist/commander completions require
  `OPENROUTER_API_KEY`.
- Without `agent`: direct completion via the inference router.
- The exchange is stored in memory under `chat:last`.

## Billing

### `GET /billing/plans`
Plan catalog (mirrors `docs/monetization.md`):
```json
[
  {"name": "Free",       "price_monthly": 0,   "features": ["1 commander", "2 specialists", "community tools", "10 req/day"]},
  {"name": "Pro",        "price_monthly": 29,  "features": ["5 commanders", "unlimited specialists", "all tools", "5k req/day"]},
  {"name": "Enterprise", "price_monthly": 299, "features": ["unlimited agents", "SSO/SAML", "Vault secrets", "SLA"]}
]
```

### `POST /billing/checkout/{plan_id}`
Starts checkout for a plan.
- `404` for an unknown plan id (`free` / `pro` / `enterprise`).
- `503` unless `STRIPE_API_KEY` is set — intentional so local dev and CI
  need no Stripe.
- With the key set: returns `{"plan": "<id>", "status": "checkout_session_created"}`.

## Errors

FastAPI default error shape:
```json
{"detail": "Unknown agent: NoSuchAgent"}
```
`404` unknown agent/plan · `503` billing unconfigured · `422` request
validation failures.

See also: [architecture.md](architecture.md) for how these endpoints are
implemented, and [blueprints.md](blueprints.md) to add agents.
